NOTE FOR THE P4LEHORSE BUILD

The licence permits free distribution provided this text file travels with
the font files. That condition is met inside this kit: keep this file in the
/fonts directory.

The .woff and .woff2 files in this directory were generated from the original
.ttf files for web delivery. The originals are included unmodified alongside
them. Serving webfont conversions of a freeware face is standard practice, but
the licence predates webfonts and does not address them explicitly. If
P4LEHORSE ever moves to paid advertising, print merchandise, or anything where
licence exposure matters, email the designer at the address above. He is on
record asking to see what people build with it, so it is a friendly email to
send, not a difficult one.

Do not host these files on a public CDN or an open directory that invites
hotlinking by third parties. Serve them from the P4LEHORSE domain only.
